# SquareSumV1 mode3-lowp-retile-rchunk 阶段经验总结

1. screening 的 15.97% 不能代替配对结论；六轮交替后同一目标的稳定改善只有 5.60%。
2. 配对轮序是必要的：全矩阵单轮 delta 从 `-41.63 us` 到 `+12.53 us`，如果只取第 1 轮会严重高估收益。
3. 低精度 R chunk 重预算是正确、无回退、且有稳定小收益的方向，但本阶段预声明要求更强，所以仍必须拒绝。
4. BF16 mode 3 必须真实上板；本轮新增后 parent/candidate 皆精硦通过，性能观测改善 7.43%。
5. 新候选应减少与数据规模成比例的实际 Vector/barrier 工作，而不只调整 chunk 数。对完全被 DMA 覆盖的 A0 tile，删除冗余清零是一个独立、可证伪方向。
