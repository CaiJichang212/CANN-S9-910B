# Greater 大 Inner 完整 P1 切片驻留方案

> 审核状态：PASS  
> 唯一实施候选：`p_large_inner_full_resident`  
> 父版本：`official_20260831_104337`

## 1. 单一假设

对完整 outer 广播且 stream operand 全连续的 P1，当 `innerSize > dtype TILE` 时，当前 Generic 对每个输出行重复读取相同广播行。将 AIV 映射为 `innerWorkers × outerWorkers`，使每个核把自己负责的 resident 切片搬入 UB 一次并跨多个输出行复用，可以降低重复 GM 搬入且保留完整并行度。

## 2. 适用谓词

```text
bcastMode == 0
&& outerDim > 0
&& outerSize > 1
&& innerSize > TILE
&& (xResidentGroupSegs == outerSize || yResidentGroupSegs == outerSize)
```

`GetResidentGroupSegs` 已同时验证 resident operand 的 outer stride 全为 0，以及 peer stride 从 `innerSize` 起按 outer shape 连续增长。没有命中时保持原 fallback。

## 3. 实现范围

- Host `TilingFunc`：镜像大-inner 完整 resident 谓词，按有效工作计算乘积型 BlockDim。
- Kernel `Init/Process`：新增 `largeResident_` 状态、大-inner worker 映射、resident slice 搬入和单 slice compare/copyout。
- TilingData、注册、公开接口、dtype 计算语义、P2、短行 P1、partial-group P1 和 Generic 不变。

## 4. Worker 布局

Host 和 Kernel 使用同一整数公式：

```text
innerTiles     = ceil(innerSize / TILE)
maxUsefulCores = min(aivCoreNum, ceil(totalSize / TILE))
innerWorkers   = min(innerTiles, maxUsefulCores)
outerWorkers   = min(outerSize, maxUsefulCores / innerWorkers)
blockDim       = innerWorkers * outerWorkers
```

Kernel 以 `coreId % innerWorkers` 取得 inner worker，以 `coreId / innerWorkers` 取得 outer worker。inner 边界按 256 元素向上对齐；每个 inner worker 可继续循环多个 TILE，因而支持 `ceil(innerSize/TILE) > aivCoreNum`。

## 5. 数据流与同步

每个 resident tile：

```text
DataCopyPad(resident GM slice -> resident TBuf)
MTE2_V
for assigned outer segments:
  TQue CopyIn(stream slice) -> Compare/Select/Cast -> TQue CopyOut(logical n)
V_MTE2
overwrite resident TBuf with next tile
```

stream 和 output 地址为 `seg * innerSize + innerOffset`。正反广播只改变 x/y 映射，不改变输出所有权。

## 6. 不变量与风险

- bool 输出精确，fp16/fp32/bf16 NaN/Inf 语义和 int32/int8 既有比较实现不变。
- DataCopyPad UB 起址保持 32 B 对齐；Compare count 上取整到 256 元素；只写逻辑 `n`。
- 最坏 UB 用 static_assert 固定，所有 dtype 小于 184 KiB 用户区。
- 风险：额外 AIV 初始化、极小 outer、TILE+1 负载不均、事件遗漏和反向 x/y buffer 映射。对应控制项和正反向用例必须先于全矩阵通过。

## 7. 冻结门槛

- 正确性：专项 dtype/方向/边界、Host 5/5、UB 5/5、mixed 40/40、sweep 85/85、full94 全部精确 PASS。
- 目标：四个 fp16/fp32 正反向大-inner P1 各自改善至少 10% 且 5 us，至少两组相邻 A/B 方向一致。
- 全局：共同 full94 P50 总和改善至少 2%。
- 回归：任一非目标或边界控制不得回退超过 `max(5%,0.5 us)`。
- 结构：目标命中新路径且 BlockDim/worker 模型一致；P2、partial-group 和 Generic 控制保持父路径。
