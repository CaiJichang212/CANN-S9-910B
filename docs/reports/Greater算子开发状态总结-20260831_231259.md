## 6. 历史候选决策

已接受的主要机制包括：路径感知核数、大连续同形扩核、UB-safe row padding、fp16/fp32 P1 批量 Vector Copy、fp16/fp32 P2 Brcb+Copy 和超预算 P2 scalar 分块。

已拒绝的主要候选包括：全路径 40 AIV、dtype TILE 粒度扩核、广播统一扩核，以及未完成 UB 总预算就解除 row-padding 门限。拒绝原因分别覆盖低工作量回退、控制集回退、完整矩阵长尾回退和 MPU 非法访问；这些候选不能重新混入父版本。
