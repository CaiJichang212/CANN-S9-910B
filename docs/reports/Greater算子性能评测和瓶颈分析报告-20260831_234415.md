> 时间：2026-08-31T23:44:15+08:00

## 1. 结论

当前官方父包在完整 outer 广播且 `innerSize > dtype TILE` 时没有进入 P1 resident 路径，而是走 Generic。公开代理中 fp16 `[8192,10000] > [1,10000]` 的 P50 为 `369.915 us`，fp32 `[4096,10000] > [1,10000]` 为 `234.689 us`；两者 BlockDim 均为 20。fp32 的 AIV MTE2 ratio 中位数为 0.983，与重复搬入广播行的成本模型一致，但 ratio 不能单独证明 HBM 饱和。

下一候选只处理一个结构缺口：对完整 outer 广播、stream operand 全连续、`innerSize > TILE` 的 P1，按 inner 切片和 outer 分区共同映射 AIV，每个核只搬入一次自己负责的 resident 切片。P2、partial-group P1、短行 P1 和 Generic 均保持原路径。

## 5. Host/Kernel 模型

当前 P1 资格要求 `innerSize <= TILE`，其中 fp16 TILE=9216、fp32 TILE=5120。两个目标的 `innerSize=10000`，因此 Host 保留 Generic 20 核，Kernel 对每个输出 segment 分别搬入 stream 行和相同的广播行。

软件逻辑字节估算如下，不等同于 profiler 实测 GM 字节：

| 目标 | 当前重复搬运模型 | 候选模型（20 outer 分区） | 预计逻辑字节下降 |
|---|---:|---:|---:|
| fp16 81.92M 元素 | 409.60 MB | 246.16 MB | 163.44 MB / 39.90% |
| fp32 40.96M 元素 | 368.64 MB | 205.60 MB | 163.04 MB / 44.23% |

候选不减少 stream 输入、比较或 bool 输出，只把广播输入从“每个输出行一次”降为“每个 outer 分区、每个 inner slice 一次”。它会把目标 BlockDim 从 20 调整为 40，同时保留按 `ceil(totalSize/TILE)` 限制小任务启核的规则。

## 6. 分区与安全模型

Host 预先计算：

```text
maxUsefulCores = min(aivCoreNum, ceil(totalSize / TILE))
innerWorkers   = min(ceil(innerSize / TILE), maxUsefulCores)
outerWorkers   = min(outerSize, floor(maxUsefulCores / innerWorkers))
blockDim       = innerWorkers * outerWorkers
```

Kernel 用同一公式从 TilingData 和编译期 TILE 复原 worker 布局。每个核唯一拥有一个 outer segment 区间和一组互不重叠的 inner 切片；切片边界向上对齐到 256 元素，最后切片只写逻辑长度。对 fp16/fp32 的两个主要目标，`innerWorkers=2`、`outerWorkers=20`、`blockDim=40`。对 `[21,10000]` fp16 控制，blockDim 受有效工作限制为 22，而不是无条件 40。

大-inner resident 最坏 UB 预算包含一个双缓冲输入队列、一个双缓冲 bool 输出队列、Compare/Select/Cast 缓冲、dtype 附加缓冲和 `TILE+256` resident 缓冲：fp16 167552 B、fp32 145024 B、bf16 148736 B、int32 141824 B、int8 155136 B，均小于项目冻结的 184 KiB 用户 UB 上限 188416 B。

## 7. 目标、控制与未知项

目标集：fp16/fp32 完整 outer 广播的正反向大-inner；正确性扩展到 bf16、int32 和由合法多维 shape 形成 `innerSize>TILE` 的 int8。

控制集：P2 大-inner、P1 `TILE-1/TILE/TILE+1`、小 outer N=10000、partial-group 大-inner、既有短行 P1、Generic、scalar，以及现有 mixed/sweep/full94。

未知项：候选绝对收益、40 核初始化成本、极小尾切片的负载平衡、官方隐藏 case 是否命中该通用路径。官方 Case2/Case5 不映射到任何本地 spec。
