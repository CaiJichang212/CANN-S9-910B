## 2. 正确性前置修复

基线冻结时新增合法广播穿刺：`x=[2,1,256]`、`y=[1,3,1]`。旧 P2 路径把外维仍需广播的 stream operand 按输出线性 offset 读取，fp32 实测 852 个 bool mismatch。

修复内容：P2 仅在非标量 operand 的 outer stride 与输出稠密 stride 一致时启用，否则回退已有通用 `ComputeBases` 路径。修复后：

- 新增混合广播回归：40/40 PASS，覆盖 5 dtype、正反向、aligned/padded/4D 和连续 P2 控制；
- 原 `acc_sweep.py`：85/85 PASS；
- 最终固定性能矩阵：79/79 精确 bool PASS。

回归脚本见 `Greater/perf_test/mixed_broadcast_regression.py`。

## 4. 最终本地候选

Host 先镜像 Kernel 已有 P1/P2 适用条件，再选择核数：

```text
generic fallback:
  min(GetCoreNumAic(), ceil(totalSize / 256))

P1 full resident:
  min(GetCoreNumAiv(), outerSize, ceil(totalSize / dtypeTile))

P1 partial resident:
  min(GetCoreNumAiv(), outerSize / residentGroupSegs,
      ceil(totalSize / dtypeTile))

P2 scalar batch:
  min(GetCoreNumAiv(), outerSize, ceil(totalSize / dtypeTile))
```

P1/P2 eligibility逐项包含 dtype TILE、256 元素 Compare 对齐、row padding、96 KiB resident、64 KiB scalar batch、resident group 和 stream/scalar continuity。通用 fallback 保留安全父版本策略。

`GetCoreNumAic()` 在 generic 公式中只是 910B 分离模式下的数值上限；实际五个 Kernel object 均为 `VectorCore/AIV`，没有启动 Cube task。
