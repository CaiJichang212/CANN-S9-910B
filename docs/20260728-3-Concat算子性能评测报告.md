# Concat P2（FlatSpan + Identity + Tiny）本地性能评测

日期：2026-07-28；目标：Ascend 910B4-1 / dav-2201；CANN：8.5.0；Python：3.9。

## 结论

**P2 在本地 39 case 矩阵上未证实有效，不能提交为总体优化。**

P2 完全通过本报告的 bitwise 正确性，但主 A/B 的五轮中只有 1 轮更快，五轮“单轮总和”的中位数只从 636.834 us 降至 632.805 us（0.64%），低于 2% 门槛；同时有 5 个超过 `max(1 us, 2%)` 的未补偿回退。因此不外推到隐藏 case、官方 500 us 门槛或排名。

## 实现范围

P2 只改动 `op/CustomOp/op_host/concat.cpp`、`op_kernel/concat.cpp` 和紧凑 tiling 的 `splitMode` 语义：

- `0/1` 保持 P0 的 Row / Row×Column；新增 `2=Tiny`、`3=FlatSpan`、`4=Identity`，不新增 tiling 字段。
- 路由优先级：单输入 Identity；多输入且总字节数不超过 64 KiB 的 Tiny（1 核）；满足总量至少 256 KiB、低 `beforeDim`、平均非空片段至少 4 KiB 的 FlatSpan；其余保留 P0 选择器。
- Identity 和 FlatSpan 以 512 B unit 切分；FlatSpan 只在 span 起点定位输入，之后按输入边界、行尾和 span 尾推进。零长度和零步长均有返回保护。
- Tiny 与不超过 64 KiB 的 Identity 用一个 64 KiB queue slot；其他路径保持 P0 的双 64 KiB `EnQue → DeQue → FreeTensor` 流水。

未引入 P1 Row2D、P3 `DataCopy` 快路、tile/阈值搜索或 L2 修改。

## 隔离与正确性

P0 从归档 `.run` 重新安装到本评测目录的私有 `p0/opp/`，P2 从本次构建 `.run` 安装到 `p2/opp/`；两者均以各自的 `ASCEND_CUSTOM_OPP_PATH` 和首位 `LD_LIBRARY_PATH` 运行。包、Host/Kernel 快照、kernel config、`.o` 与实际 `libcust_opapi.so` 的 SHA-256 见 `Concat/perf_eval/20260728_p2/metadata/`。

- P0：60/60 bitwise 用例通过。
- P2：60/60 bitwise 用例通过；7 个 P2 边界用例各连续重复 10 次通过。
- 覆盖四种注册 dtype、rank 1–7、正/负 dim、0/1/8/64/255/256 输入、零长度、非 32 B 行、宽行、`>64 KiB`、`blockCount=4095` 范围和 12 个 seed `20260721` 随机用例。

原始日志：`correctness/p0_full_matrix.log`、`correctness/p2_full_matrix.log`、`correctness/p2_boundary_repeat10.log`。

## 主 P0/P2 A/B

每个版本/轮次为一个 39 case × 30 task 的 msprof batch；解析器断言每个 CSV 恰有 1170 条 `Concat` task，丢弃每组首条，统计 29 条热样本的 P50。五轮按 P0/P2、P2/P0 交替运行。

| 轮次 | P0 总 P50 (us) | P2 总 P50 (us) | P0/P2 | P2 改善 |
|---|---:|---:|---:|---:|
| 1 | 626.035 | 627.438 | 0.9978 | -0.22% |
| 2 | 636.834 | 645.323 | 0.9868 | -1.32% |
| 3 | 639.587 | 647.276 | 0.9881 | -1.19% |
| 4 | 639.262 | 623.574 | 1.0252 | +2.52% |
| 5 | 623.852 | 632.805 | 0.9859 | -1.41% |
| 中位数 | 636.834 | 632.805 | 1.0064 | +0.64% |

逐 case 的中位数中 P2 更快 21/39；但只有 1/5 轮总和更快。按 P2 路径投影分组的 case-speedup 中位数为：Tiny 0.8940、保留 P0 Row/Column 或未命中 FlatSpan 1.0424、Identity 2.5232。Identity 的局部收益真实存在，却不足以抵消 Tiny 的广泛回退。

| 代表 case | P0 P50 (us) | P2 P50 (us) | P0/P2 | 说明 |
|---|---:|---:|---:|---|
| `single_input_large_row_fallback` | 8.632 | 3.421 | 2.523 | Identity 最大收益 |
| `rank7_int32_axis0` | 7.727 | 3.098 | 2.494 | Tiny 局部收益 |
| `fragmented_256_fp32` | 60.946 | 58.271 | 1.046 | P0 路径小收益 |
| `input_count_8_fp16` | 5.774 | 11.006 | 0.525 | Tiny 回退 +5.232 us |
| `input_count_64_int32` | 11.187 | 23.884 | 0.468 | Tiny 回退 +12.697 us |

其余超过 `max(1 us, 2%)` 的回退为 `fp16_boundary_lengths_unaligned_row`（+1.106 us）、`generated_03_rank4_int8`（+1.368 us）和 `generated_09_rank3_float16`（+1.167 us）。这些回退没有由关键路径的总体收益补偿。

完整样本、配对轮次、case 汇总和总和在 `ab_samples.csv`、`ab_paired_rounds.csv`、`ab_case_summary.csv`、`ab_total_by_round.csv`。

## P2 专项与深度证据

专项 profile 也是每 case 30 task、丢弃首条。Tiny 维持 1 核、2 MiB Identity 使用 32 核、三个低 `beforeDim` FlatSpan 使用 40 核，符合固定调度规则。

| P2 专项 | Path / BlockDim | P50 (us) |
|---|---|---:|
| 64 KiB fp16 多输入 | Tiny / 1 | 4.890 |
| 小型非对齐 fp32 | Tiny / 1 | 4.487 |
| 64 KiB int8 单输入 | Identity 单槽 / 1 | 3.581 |
| 2 MiB fp32 单输入 | Identity / 32 | 8.249 |
| 256 KiB fp16 临界 | FlatSpan / 40 | 8.611 |
| B=1 int8 512 B 尾 | FlatSpan / 40 | 8.914 |
| B=1 int32 512 B 尾 | FlatSpan / 40 | 8.914 |
| 256 路 fp16 控制 | P0 control / 40 | 260.730 |

七组指标的 PipeUtilization 深采集显示：

| case | P0：Scalar/MTE2/MTE3 | P2：Scalar/MTE2/MTE3 | 解释 |
|---|---|---|---|
| 64 KiB Tiny | 55.9% / 44.3% / 4.4% | 54.9% / 28.3% / 14.8% | 小任务同步/发射开销显著 |
| 2 MiB Identity | 36.6% / 54.6% / 12.4% | 42.2% / 51.6% / 9.2% | 仍主要受 GM 读搬运限制 |
| B=1 int8 FlatSpan | 46.1% / 47.9% / 35.9% | 45.8% / 54.0% / 4.6% | FlatSpan 写搬运重叠下降，深采集时延反而变慢 |
| B=1 int32 FlatSpan | 48.9% / 48.8% / 36.9% | 45.7% / 53.7% / 4.6% | 同一回退模式 |
| 256 路 fp16 控制 | 2.4% / 86.6% / 28.3% | 2.4% / 84.9% / 32.0% | 依旧 MTE2 bound；Vector=0 |

Vector ratio 近零、256 路控制仍为 MTE2 bound，未观察到 UB bank/resource conflict 是主因。两份 sample-based `aicore.db` 已归档；不以 sample 的 `task_cyc` 做逐核均衡结论。

专项及深度原始数据分别在 `p2_special_valid/`、`p2_special_summary.csv`、`deep/`、`deep_summary.csv` 和 `deep_sample_manifest.txt`。此前误发射 7200 task 的专项试运行保留在 `p2_special/`，明确不参与任何表格或结论。

## 内置对照

内置对照在全新进程中移除 `ASCEND_CUSTOM_OPP_PATH`，且不注入 custom `op_api/lib`。首个 P2 专项形状的 bitwise 检查失败，因此该组 **不能作为正确的性能基线**；仅记录其 task 类型为 `AI_VECTOR_CORE`、Block Dim 为 1、丢弃首条后的 29-task P50 为 4.104 us。原始 profile 与表格在 `builtin/`、`builtin_summary.csv`。

## 判定

规则要求：正确性全过、至少 4/5 轮总和更快、五轮中位总和至少改善 2%，且重要回退有明确补偿。P2 仅满足正确性，未满足后三项，结论为 **未证实有效**。建议保留实现与完整证据，但默认回到 P0；若后续继续探索，应优先隔离 Tiny 单槽带来的小任务回退，并重测 FlatSpan 的 MTE2/MTE3 重叠，而非将本次局部 Identity 收益当作整体优化。
